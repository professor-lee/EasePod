# 主界面音乐来源目录

登录后的云账号可以成为宿主的当前音乐来源。插件声明 `catalog.home` 和 `catalog.browse` 后，宿主通过既有 `Browse` 请求访问下列 `HomeCatalog` 目录键。`RequestEnvelope` / `ResultEnvelope` 和协议版本保持不变；未声明新能力的插件仍使用原先的 `Browse` 根目录。

| `remoteId` | 用途与返回内容 |
|---|---|
| `home` | 当前账号可用的目录入口，每个条目的远端标识可继续 Browse / GetDetails |
| `home:covers` | 主界面 Cover Flow，返回带封面的专辑或歌单；允许只有部分条目有封面 |
| `home:playlists` | 当前账号的歌单，包括自己创建及已收藏的歌单 |
| `home:tracks` | 当前账号的个人歌曲集合，插件应说明服务实际采用的集合语义 |
| `home:albums` | 当前账号收藏或拥有的专辑 |
| `home:artists` | 当前账号关注或收藏的歌手 |
| `home:genres` | 服务提供的音乐流派入口 |
| `home:favorites` | 当前账号喜欢的歌曲 |
| `home:daily` | 当前账号的每日推荐歌曲；宿主将它作为 Cover Flow/歌单中的只读虚拟歌单呈现 |
| `home:netease:radar` | 网易云私人雷达歌曲；网易云插件扩展键，作为只读虚拟歌单呈现 |
| `home:netease:roam` | 网易云歌曲漫游歌曲；网易云插件扩展键，作为只读虚拟歌单呈现 |

`home:*` 为契约保留目录命名空间。请求必须使用明确的已登录账号；`public` 请求返回 `AuthRequired`。全部操作均为只读，不触发收藏或歌单修改。能力表明插件理解这些目录键，并不要求上游提供每一种集合；不支持的目录返回 `Unsupported`，不能用其他集合或伪造条目填补。有效空集合返回成功与空 `items`，认证失败、网络失败、上游数据缺失必须保留对应错误。可选且不支持的目录不应出现在 `home` 返回的入口中。

每页最多 50 项，继续使用不透明 `nextCursor`，并将游标绑定账号、请求目录、页大小等查询条件。宿主按原请求继续翻页；不能在 `home:covers` 与 `home:playlists` 等目录之间共享游标。列表条目使用服务提供的稳定远端标识；打开专辑、歌手和歌单后继续使用 `Browse` / `GetDetails`。账号切换、退出、失效与插件停用均使当前页面请求失效，宿主不能把旧账号结果放入新来源。

网易云映射：Cover Flow 和歌单使用用户歌单，并在两者开头插入每日推荐、私人雷达、歌曲漫游三个只读虚拟歌单；歌曲和喜欢使用喜欢歌曲 ID 的完整分页，每日推荐使用推荐歌曲，专辑和歌手分别使用收藏专辑与收藏歌手列表。网易云没有在本适配器中提供个人流派目录，因此 `home:genres` 返回 `Unsupported`。旧的公开推荐根目录和 `category:*` 入口保留原行为。
